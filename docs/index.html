Where a $15 Pi runs out of road

A Raspberry Pi Zero 2 W serving a cached package through Artifact Keeper's TLS proxy. We ramped parallel clients from 1 to 128 to find the ceiling. It holds ~52 requests/second, then throughput collapses — and the wall is the 2.4 GHz Wi‑Fi, not the CPU.

03

What actually saturated

The tell: network throughput plateaus at ~30 Mbps exactly where req/s does, while the backend never burns even a full core. Errors and heat climb with the queue, not the compute. This box is network‑bound.

04

Cold cache costs the most

Separate single-client test: a first (cold) pull makes the proxy fetch from upstream, verify, and cache; a warm pull just streams from disk. Warm serving is 2–5× cheaper in backend CPU — the strongest lever on a small box is cache hit‑rate.

05

What it would take to go faster

NET

Wire it up. Throughput and net Mbps top out together at ~30 Mbps — the Zero 2 W's single-band 2.4 GHz radio. A board with Ethernet (Pi 4/5, CM4) is the single biggest win; the proxy has CPU to spare.

CONC

Cap concurrency at ~8. Beyond the knee the box does less work and fails more. A small connection limit (nginx limit_conn) keeps latency sane under a stampede instead of collapsing.

CACHE

Pre-warm hot packages. Cold pulls cost 2–5× the CPU and pull from upstream over that same thin radio. A high cache hit-rate is what keeps this board cool and quick.

RAM

Move Postgres off-box (or add RAM). It — not the ~20–90 MB backend — is what forces this 415 MB board onto swap; the binary itself is genuinely light.

TUNE

Cool it and tune it. This ran on a stock, heatsink-less board already touching 63 °C, on default OS and network settings — all untapped headroom. A heatsink plus basic tuning lifts the whole curve. Everything here is the floor, not the ceiling.

Method. Client drives a keep-alive concurrency sweep (loadgen.py) from a dev machine against the Pi's nginx TLS proxy; a 0.25 s sampler on the Pi records server-side CPU, memory, load, temperature and network per level. Each level runs 10 s. CPU % is of one core (the box has four). Reproducible via ak-pi-zero-benchmarks/run_all.sh + bench_load.sh. Single run, 2026-08-17 — treat as indicative, not a datasheet. Full framework, raw data & scripts: github.com/brandonrc/ak-pi-benchmark.
